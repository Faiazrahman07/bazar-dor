# bazar-dor

## About
BazarDor is a responsive web application that helps users explore daily essential product prices and market information.

## Technologies Used
* Next.js
* React
* TypeScript
* Tailwind CSS
* BetterAuth
* REST API

## Key Features
1. Browse daily product prices.
2. Explore product details and market prices.
3. User authentication with social login.
4. Update user profile information.
5. Responsive design for all devices.
